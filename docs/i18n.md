# 語言、中文字體與 Emoji

Rillway 支援英文 `en` 與繁體中文 `zh-Hant`，預設為英文。Web UI、TUI 與 CLI
各自選擇語言，不改變 daemon 的路由設定、規則 ID、JSON 欄位或 VPN 狀態。

## Web UI

登入畫面及側欄都有語言選單，可切換 **English**／**繁體中文**。語言偏好保存在
這個瀏覽器的 `localStorage`，重新整理後仍保留；登入 token 仍只保存在該分頁的
`sessionStorage`。切換語言不登出、不切換頁面，也不清除尚未送出的表單內容。

標籤、按鈕、說明、可存取名稱、提示及日期會隨語言更新。瀏覽器使用 `Accept-Language`
向管理 API 要求對應語言；API 的狀態代碼、設定欄位及使用者資料維持原值。

Web UI 內建完整 Noto Sans TC 中文字體及 Noto Color Emoji 備援字體，與程式一起
發布，不連接外部字體服務。系統有 Apple Color Emoji／Segoe UI Emoji 等彩色
字體時會優先使用。字體來源、校驗值與授權見 [字體清單](brand/fonts.md)。

介面預覽：[繁中桌面版](screenshots/web-zh-Hant.png)、[英文桌面版](screenshots/web-en.png)、
[繁中手機版](screenshots/web-zh-Hant-mobile.png)。截圖使用本機測試流量，不含帳號或權杖。

## CLI 與 TUI

```sh
./bin/rillway --lang zh-Hant help
./bin/rillway tui --lang zh-Hant --config .local/config.json
RILLWAY_LANG=zh-Hant ./bin/rillway service status --config .local/config.json
./bin/rillway --lang en help
```

`--lang` 優先於 `RILLWAY_LANG`；沒有設定時使用英文。TUI 按大寫 **L** 即時切換
語言，保留目前頁籤與選取項目。文字輸入中改按 **Ctrl+L**，避免攔截授權碼裡的
大寫 L；Ctrl+L 也適用於一般頁面。小寫 **l** 仍是 WARP+ license 操作。

TUI 依 Unicode 字素及顯示欄寬裁切文字，避免將中文字、組合字、國旗、膚色或
ZWJ Emoji 拆開。字體由目前的 Terminal 提供，Go 程式無法指定遠端 SSH 客戶端
的字體。請使用 UTF-8 終端及支援中文、Emoji 的字體；Web UI 的內建字體不會
安裝到作業系統。少數終端的 Emoji 欄寬判斷仍可能與 Unicode 規則不同。

## 翻譯維護

- `internal/i18n`：語言正規化、管理 API 共用訊息、context 語言偏好。
- `internal/control/web`：Web UI 字串與 DOM 更新。
- `internal/tui/catalog.go`、`cmd/rillway/catalog.go`：TUI／CLI 字串。
- 新增產品文字時，同步提供英文與繁中，並以測試確認字串與參數完整。
- 只翻譯 Rillway 已知的完整訊息或格式模板。使用者輸入的名稱、網域、路徑、
  provider 識別碼與未知的上游錯誤保持原文，不做子字串取代。
- 錯誤仍先經過既有秘密遮罩；選擇中文不會放寬 API 可揭露的內容。

管理 API 保留 `error`／`detail` 作為對應語言的文字，另外提供已遮罩的英文
`error_source`／`detail_source`，讓客戶端切換語言時重新顯示。這些欄位不是原始
上游錯誤；缺少 source 的舊伺服器訊息保持原文，不反向猜測翻譯。

一般測試使用 `mise run check`，包含 locale 協商、字串 fallback、表單狀態保留、
API 語言與 Emoji 字寬。不同作業系統／終端實際渲染仍需各平台驗收。
